Chat with your own files - in plain English

A friendly, step-by-step manual for building a local-first retrieval assistant: chunking, embeddings, vector stores, local models (Ollama/llama.cpp), and citation sanity checks. Your files never leave your machine.

Start here

  • Read the 8 chapters in the sidebar.
  • Run the pipeline: python3 examples/01-index.py docs --index /tmp/opencode/idx.json
  • Ask it something: python3 examples/02-ask.py /tmp/opencode/idx.json "How much overlap?"
  • Check yourself: python3 examples/03-tests.py --index /tmp/opencode/idx.json --run-suite
