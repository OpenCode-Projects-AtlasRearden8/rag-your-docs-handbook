# STATUS.md

Project: **RAG Your Docs Handbook** — a beginner manual plus working reference
pipeline for chatting with your own files using retrieval, local-first with
Ollama/llama.cpp, no secrets.

Maintained by Asdale Dynamics, LLC.

## What was built

- **`docs/`** — an 8-chapter manual in plain English:
  `00-introduction`, `01-chunking`, `02-embeddings`, `03-vector-stores`,
  `04-local-vs-api`, `05-tool-comparison`, `06-pipeline-walkthrough`,
  `07-citations`. Every requested topic is covered: chunking, embeddings,
  vector stores, local vs API, tool comparisons, pipeline walkthroughs, and
  citation sanity checks.
- **`examples/`** — a complete runnable pipeline in stdlib Python only:
  - `raglib.py` — chunker (recursive, size+overlap, metadata), deterministic
    local mock embedder, cosine search, JSON index store, citation checker,
    mock (fail-closed extractive) generator, and optional Ollama generator
    (localhost only).
  - `01-index.py` — builds an index from any `.md`/`.txt` folder.
  - `02-ask.py` — retrieval + answer with citations and automatic citation
    validation (exit code 2 on citation failure).
  - `03-tests.py` — 7 unit tests plus an end-to-end suite
    (`--index ... --run-suite`).
- **`site/`** — static HTML site with a sidebar (one page per chapter plus a
  landing page), generated by **`scripts/build-site.py`** (also stdlib only;
  `site-src/style.css` is the stylesheet source).
- **`README.md`**, **`LICENSE`** (MIT, "Copyright (c) 2026 Asdale Dynamics,
  LLC"), **`.gitignore`**.

## How to run it

```bash
python3 examples/01-index.py docs --index /tmp/opencode/handbook-index.json
python3 examples/02-ask.py /tmp/opencode/handbook-index.json "How much overlap should chunks have?"
python3 examples/03-tests.py --index /tmp/opencode/handbook-index.json --run-suite
python3 scripts/build-site.py                # rebuild site/
```

Optional real local generation:

```bash
ollama pull llama3.2:3b
python3 examples/02-ask.py /tmp/opencode/handbook-index.json "..." \
    --provider ollama --model llama3.2:3b
```

## Known gaps

- The default embedder is a deterministic hashing mock (no synonym
  understanding) so the repo runs with zero downloads; real quality needs a
  real local embedder (Ollama `nomic-embed-text` or sentence-transformers
  MiniLM) — the swap point is documented in Chapter 02.
- The mock generator is extractive (quotes index sentences); real conversational
  answers require the optional Ollama provider.
- PDF indexing not yet built (text-extraction step documented as an extension
  in Chapter 06); only `.md`/`.txt` are indexed.
- The mini markdown renderer in `scripts/build-site.py` covers headings,
  lists, tables, fences, links, and emphasis but not blockquotes/images.
- No pip/dependency story needed — intentionally none ("nothing to install"
  is the privacy-correct feature), so no wheel/packaging checks apply.
